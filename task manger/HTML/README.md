# TaskPro Elite 🚀

TaskPro Elite is a modern task management web application designed to improve productivity with an elegant UI, Kanban workflow, AI-powered assistance, analytics dashboard, and responsive design.

---

## ✨ Features

- ✅ Add, Edit & Delete Tasks
- ✅ Drag & Drop Kanban Workflow
- ✅ AI Copilot Integration
- ✅ Analytics Dashboard
- ✅ Dark / Light Mode
- ✅ Responsive Mobile Design
- ✅ Search & Category Filters
- ✅ Toast Notifications
- ✅ Task Priorities & Categories
- ✅ Real-Time Progress Tracking

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Gemini API
